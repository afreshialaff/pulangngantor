Kebijakan Privasi

Terakhir diperbarui: 17 November 2026

Aplikasi "Pulang ngantor" adalah alat pribadi milik pemilik channel YouTube Pulang ngantor untuk mengunggah video, thumbnail, subtitle, dan playlist ke channel miliknya sendiri melalui YouTube Data API v3.

Data yang diakses

Aplikasi hanya mengakses akun Google dan channel YouTube milik pemilik aplikasi, dan hanya setelah pemilik memberi izin lewat layar persetujuan Google. Izin yang dipakai: mengunggah video dan mengelola channel milik pemilik.

Penyimpanan dan penggunaan

Token akses disimpan sebagai secret terenkripsi di GitHub Actions milik pemilik dan hanya dipakai untuk menjalankan unggahan yang diminta pemilik. Aplikasi tidak mengumpulkan data pengguna lain, tidak menjual atau membagikan data kepada pihak ketiga, dan tidak menampilkan iklan.

Kepatuhan

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Aplikasi juga tunduk pada Ketentuan Layanan YouTube dan Kebijakan Privasi Google.

Mencabut akses

Pemilik dapat mencabut akses kapan saja di myaccount.google.com/permissions.
